# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A pixel-only computer-use agent that plays Slay the Spire 2. See `README.md` for the architecture, model choices, and build order.

## Git Workflow

- **Pushing is fine without asking.** Commit and push freely, and open PRs.
- Do feature work on a branch and open a PR into `main`.

## Scope

Slay the Spire 2 only. Don't use or reference Slay the Spire 1 tools, mods, or UI as a source of truth; confirm everything against Spire 2 itself.
